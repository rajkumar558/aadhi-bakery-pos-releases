# AADHI Bakery Pos – Installers

Windows installers for **AADHI Bakery Pos** by Mahanya Technologies.

- **New install:** open [Releases](../../releases/latest) and download `AADHI-Bakery-Pos_<version>_x64-setup.exe`.
- **Already installed (0.1.5 or later):** the app shows an update banner by itself – no download needed.
- **No internet at the shop:** copy the same setup.exe by pendrive and run it. Your data is kept.

Every installer is signed; the app refuses updates that aren't.
